## Sobre o projeto

A **AUREN NOIR** é uma marca fictícia de perfumaria masculina premium, desenvolvida como projeto de portfólio para demonstrar habilidades em desenvolvimento Front-end, design de interfaces e criação de experiências digitais.

O objetivo foi construir uma landing page elegante e imersiva, combinando fotografias de campanha, tipografia refinada, tons escuros e detalhes dourados para transmitir a essência de uma marca de luxo.

Mais do que apresentar um produto, a proposta é transformar a navegação em uma experiência visual.

## Identidade visual

- **Conceito:** luxo, elegância e exclusividade.
- **Paleta:** preto profundo, dourado e tons neutros.
- **Tipografia:** Cormorant Garamond e DM Sans.
- **Estilo:** minimalista, editorial e sofisticado.

## Executando o projeto

### Pré-requisitos

- Node.js
- npm
- Git

### 1. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 2. Entre na pasta

```bash
cd auren-noir
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

O Vite disponibilizará um endereço local para acessar a aplicação pelo navegador.

### 5. Gere a versão de produção

```bash
npm run build
```

O projeto foi desenvolvido considerando diferentes resoluções de tela, com adaptações de layout, tipografia, imagens e navegação.

A experiência busca manter consistência visual tanto em monitores maiores quanto em dispositivos móveis.
